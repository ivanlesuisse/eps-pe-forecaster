# Swiss FinTrack

Swiss FinTrack is a financial dashboard built with Next.js, Prisma, and Clerk. It includes secure IBKR OAuth 1.0a integration, portfolio syncing, and audit logging.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## IBKR Setup
